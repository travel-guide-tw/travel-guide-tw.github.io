# 三峯神社

三峯神社座落於三峰山約 1,100 公尺高處，是秩父三社之一。神社以山林環境、具彩色雕刻的拜殿、隨身門與日本武尊像為主要看點，也可在遙拜殿眺望奧宮所在的妙法岳方向。

## 參拜提示

- 三峯神社位於山區，與秩父市中心距離較遠，建議安排半天以上，不要與市區景點排得過於緊湊。
- 公車班次與道路狀況可能受季節、天候及活動影響，請於出發前查看西武觀光巴士與神社官方公告。
- 冬季自駕前往可能遇到路面結冰，冬季行車務必使用冬季輪胎；停車場為收費設施，開放時間也可能調整。

## 基本資訊

- **地址：** 〒369-1902 埼玉縣秩父市三峰 298-1
- **停車場：** 有，收費；開門時間請以官方公告為準。

## 交通方式

- 從西武秩父站或秩父鐵道三峰口站搭乘西武觀光巴士，在終點「三峯神社」下車。
- 自駕可使用秩父市營停車場；山路彎道較多，冬季務必先確認路況。
