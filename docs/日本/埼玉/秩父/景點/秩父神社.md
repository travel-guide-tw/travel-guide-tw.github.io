# 秩父神社

秩父神社是秩父地方的總鎮守，創建相傳已有約 2,000 年。現存本殿為權現造，保留德川家康重建時的建築特色，並以左甚五郎作傳說中的「つなぎの龍」、北辰之梟與「お元気三猿」等雕刻聞名。

## 看點

- 本殿的彩色雕刻與四面不同主題的裝飾。
- 每年 12 月 2、3 日舉行的秩父夜祭，是秩父神社的重要例大祭，相關祭典資訊請以官方公告為準。
- 神社位於市中心，可與秩父站、番場通商店街及西武秩父站周邊景點安排在同一天。

## 基本資訊

- **地址：** 〒368-0041 埼玉縣秩父市番場町 1-3
- **參拜費用：** 境內參拜免費；授與所與特別活動請依現場公告。

## 交通方式

- 從秩父鐵道秩父站步行約 3 分鐘。
- 從西武秩父線西武秩父站步行約 15 分鐘。
